# 👾 Discord Gif Machine (≤ 8MB)

Aplicação web minimalista para converter vídeos e mídias do Twitter/X em GIFs perfeitamente otimizados para o **limite de 8MB do Discord**, com suporte a **Legendas (Captions)** no estilo clássico de memes do Discord (esmbot / Tenor).

---

## ⚡ Como Usar

1. Dê um **duplo clique** no arquivo **[`index.html`](file:///c:/Users/aluno/Documents/GIF%20Downloader/index.html)** para abrir no navegador.
2. Cole o link do tweet (ou arraste um vídeo do computador).
3. **Adicionar Legenda (Opcional)**:
   - Clique no botão **`+ adicionar legenda (caption)`**.
   - Digite o texto do meme. Uma barra branca superior com a fonte **Futura Condensed Extra Bold** aparecerá em tempo real em cima do vídeo.
4. Selecione o modo de conversão:
   - **Discord (≤ 8MB)**: Otimizado com garantia estrita de até 8MB para envio livre no Discord.
   - **Conversão Padrão (≤ 20MB)**: Maior resolução e taxa de quadros (FPS).
5. Clique em **"Gerar GIF para Discord"** &rarr; **"Baixar GIF"** ou **"Copiar"**.
